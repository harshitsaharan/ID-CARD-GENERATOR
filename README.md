🪪 Customizable ID Card Generator

A web-based application that allows users to design and generate personalized ID cards using predefined templates. It features real-time customization options, including text positioning, font style, and color adjustments, along with a live preview and print-ready export.

---

## 🚀 Features

### **1. Predefined Templates**

Choose from built-in ID card templates or upload your own custom background.

### **2. Text Customization**

* Edit participant **Name** and **College/Team Name**
* Move text freely within the card
* Change **font family**, **font size**, and **text color**

### **3. Live Preview**

Real-time preview updates instantly with every change, allowing accurate adjustments.

### **4. Print-Ready Export**

Export your final ID card as:

* **High-resolution PNG/JPEG**
* **PDF** (standard ID card dimensions)

---

## 🛠️ Tech Stack

* **React.js** (Frontend)
* **HTML5 Canvas / html2canvas** (Screenshot rendering)
* **jsPDF** (PDF generation)
* CSS (Styling)

---

## 📘 How to Use

1. Select a predefined template.
2. Enter the participant’s **Name** and **College/Team Name**.
3. Drag and reposition text fields as needed.
4. Customize text colors and font style.
5. Preview changes live.
6. Export the final ID card as **PDF** or **Image**.
